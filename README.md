# Top 200 Free & Open-Source Software

A curated discovery catalogue covering desktop applications, development, media, graphics, AI, security, networking, knowledge management, business, science, and games.

## How to interpret "free/open-source"

The catalogue aims at software distributed under licenses compatible with recognized free/open-source principles. The Open Source Initiative explains that open source requires more than source-code visibility: users must have rights including use, modification and redistribution under the applicable license.

## Use this as a discovery map

This is not a list of 200 programs that you should install. It is a **software map**:

- discover alternatives when you need a task;
- prefer mature projects for important work;
- check the project's current license and platform support before installation;
- on Linux, prefer your distribution repositories, Flatpak, or official project packages where appropriate.

The catalogue deliberately mixes cross-platform software with strong Linux options.
