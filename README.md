# 🧭 How to Use the Library

This library is intentionally designed as a **discovery system**.

It is not:

- ❌ an installation checklist
- ❌ a collection of every available application
- ❌ a popularity contest
- ❌ a list where quantity is the objective

Instead:

### 1. Identify a need

> "I need a PDF tool."

### 2. Open the appropriate catalogue

> FOSS → PDF & Documents

### 3. Shortlist candidates

Choose two or three promising options.

### 4. Evaluate

Consider:

- Features
- Stability
- Development activity
- License
- Platform
- Hardware requirements
- Ease of use
- Community
- Documentation

### 5. Adopt only what is useful

Keep the computer lean.

# 🔐 Open-Source & Licensing

"Free" and "open source" are not necessarily identical concepts.

Where licensing matters, check the **current official project license** before using, modifying or redistributing software.

The Open Source Initiative provides the recognized **Open Source Definition**:

**https://opensource.org/osd**

Individual projects may use different licenses and may change licensing over time.

---

# 🐧 Linux Installation Philosophy

For Linux software, prefer appropriate sources such as:

1. Distribution repositories
2. Flatpak
3. Official project packages
4. AppImage
5. Source compilation

The best option depends on the application and the Linux distribution.

---

# 🤖 Local AI Philosophy

The LLM catalogue follows a similar principle:

> **Catalogue many possibilities, run only the few that are useful.**

There is no need to download dozens of models.

A small collection of excellent models is usually more useful than a huge collection of unused models.

Evaluate models according to the task:

- Reasoning
- Writing
- Coding
- Translation
- Research
- Roleplay
- Creative writing
- Context length
- Speed
- Memory requirements
